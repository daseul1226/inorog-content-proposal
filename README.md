# INOROG Content Proposal

미팅에서 이노님께 보여줄 콘텐츠 제안용 반응형 정적 웹페이지입니다.

## 구성

- `index.html`: 발표용 웹페이지
- `styles.css`: 쿨그레이·화이트·연핑크 기반의 cosy scrapbook 스타일
- `script.js`: 레퍼런스 슬라이드와 이미지 확대 기능

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. 저장소 Settings → Pages로 이동합니다.
3. Branch를 `main`, folder를 `/root`로 선택합니다.
4. 생성된 Pages URL을 미팅에서 열면 됩니다.
